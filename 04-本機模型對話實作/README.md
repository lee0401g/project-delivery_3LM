# 單元 04 本機模型對話實作

## 1 教學目標

- 學生能下載並選擇課程指定的本機模型
- 學生能透過 Open WebUI 與模型對話
- 學生能進行連續提問並要求模型調整回答
- 學生能確認模型與對話資料保留在本機環境中

## 2 必要觀念

### 模型需要先下載

- Ollama 與 Open WebUI 是執行及操作模型的工具，本身不包含本單元要使用的對話模型
- 第一次下載模型需要網路，下載完成後可在沒有網路的情況下進行本機對話
- 模型會儲存在 Ollama 的 Docker volume，停止容器不會刪除模型

### 本單元使用的模型

本課程使用 Gemma 3 4B
```text
gemma3:4b
```
- Gemma 3 4B 由 Google 開發，Ollama 模型檔案約為 3.3 GB，支援文字、圖片及多語內容
- Gemma 採用 **Google Gemma 使用條款**，教材與 GitHub 不包含或重新散布模型檔案，每位學生應透過 Ollama 自行下載
- 閱讀授權問題，請參閱 [補充教材-模型授權與使用條款](補充教材-模型授權與使用條款.md)
- 需要依硬體或用途選擇備用模型時，請參閱 [補充教材-模型選擇與比較](補充教材-模型選擇與比較.md)
- 需要了解模型基本功能並比較實際表現時，請參閱 [補充教材-模型基本能力與測試](補充教材-模型基本能力與測試.md)

### 多輪對話

- 在同一個對話中繼續提問，模型會參考前面的問題與回答
- 建立新對話後，新的對話不會自動沿用上一個對話的內容

## 3 要點

- 模型系列、模型規模與完整標籤 `gemma3:4b` 代表不同資訊
- 下載模型、選擇模型與開始對話是三個不同動作
- 同一個對話會保留前文，建立新對話則不會沿用原有內容
- 對話時應觀察回答速度、繁體中文品質與指令遵循情形
- 模型回答可能出現錯誤，重要內容仍需由使用者查核

## 4 實作

### 步驟一 啟動服務

1. 啟動 Docker Desktop
2. 等待 Engine running
3. 在 `03_service-control.cmd` 上按兩下
4. 選擇 `1 Start Ollama and Open WebUI`
5. 等待預設瀏覽器開啟 Open WebUI
6. 登入自己的本機帳號

### 步驟二 下載模型

1. 開啟管理員設定
2. 進入 Connections
3. 找到 Ollama 連線並選擇管理模型
4. 輸入 `gemma3:4b`
5. 開始下載並等待完成

> 下載時間會受到模型容量與網路速度影響

> 下載期間不要關閉 Docker Desktop 或重新啟動電腦

### 步驟三 建立第一個對話

1. 回到新對話畫面
2. 從模型清單選擇剛才下載的模型
3. 輸入下列問題

```text
請使用繁體中文，以三點說明你可以協助我完成哪些學習工作
```

確認模型使用繁體中文回答且內容可以正常顯示

### 步驟四 進行連續追問

在同一個對話中依序輸入

```text
將剛才的回答改成表格
```

```text
從表格中選出最適合整理教材的一項，並說明理由
```

觀察模型是否能接續前面的回答

### 步驟五 測試新對話

1. 建立一個新對話
2. 詢問 `我上一個對話選了哪一項`
3. 觀察模型是否表示缺少前一個對話的內容

若模型直接猜測答案，不代表它真的讀取了上一個對話

### 步驟六 確認資料保留

1. 關閉目前的瀏覽器分頁
2. 再次開啟 [http://localhost:3000](http://localhost:3000)
3. 登入後確認剛才的對話仍在歷史紀錄中
4. 確認已下載模型仍可從模型清單選擇

## 5 成功檢查

完成本單元時應符合

- `gemma3:4b` 已完成下載
- 模型可從 Open WebUI 的模型清單選擇
- 能取得繁體中文回答
- 能在同一個對話中進行連續追問
- 能建立不沿用先前內容的新對話
- 關閉並重新開啟瀏覽器後對話仍然存在

## 6 常見問題與排除

### 找不到可選擇的模型

確認模型下載已完成，再重新整理 Open WebUI，若仍未出現，確認 Ollama 服務狀態為 Up

### 模型下載長時間沒有完成

確認電腦仍可連接網路並保留足夠磁碟空間，不要在下載途中停止 Ollama 容器

### 回答速度太慢

關閉不需要的應用程式並重新測試，若仍然太慢，可依補充教材改用負擔較低的模型

### 模型沒有使用繁體中文

在問題開頭明確加入 `請使用繁體中文回答`，若多次要求後仍無法穩定回答，可依補充教材更換模型

### 回答內容看起來不正確

本單元尚未加入個人文件，模型可能回答錯誤或產生沒有依據的內容，先練習操作與對話，不要把回答直接當成可靠資料

## 7 單元成果

學生完成第一個本機模型下載，建立可保留的多輪對話，並確認自己的電腦能以可接受的速度執行所選模型
