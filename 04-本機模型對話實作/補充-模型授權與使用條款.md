# 補充教材-模型授權與使用條款

## 免費、公開權重與開源授權

| 概念 | 意義 |
| --- | --- |
| 免費 | 目前不需要支付模型下載或本機推論費用 |
| 公開權重 | 使用者可以取得模型權重並在自己的電腦執行 |
| 開源授權 | 需要檢查是否允許使用、修改與散布，以及必須遵守哪些條件 |

| 授權 | 使用與修改 | 重新散布時的主要要求 | 用途限制 |
| --- | --- | --- | --- |
| Gemma Terms | 允許但受 Google 條款約束 | 傳遞條款、使用限制與指定 Notice | 受 Gemma 禁止用途政策限制 |
| MIT | 允許 | 保留版權與授權聲明 | 無額外用途限制 |
| Apache 2.0 | 允許 | 附授權文件、保留適用的 NOTICE 並標示修改 | 無額外用途限制 |

MIT 與 Apache 2.0 是 OSI 認可的開源授權

OSI 是 Open Source Initiative（開放原始碼促進會）的縮寫，負責維護開源定義並審核授權是否允許自由使用、修改與分享。OSI 認可只表示授權符合其開源定義，不代表模型品質、安全性或所有使用情境都已獲得法律保證

Gemma 使用 Google 專屬條款，更適合稱為 **免費公開權重模型**

## Gemma Terms 的主要概念

- 使用者可以使用、重製、修改及散布 Gemma，但必須遵守 Gemma Terms
- Gemma 禁止用途政策屬於條款的一部分
- Distribution 包含提供模型或衍生模型，也包含透過 Web、API 或其他遠端方式提供功能的 Hosted Service
- Google 不主張使用者透過 Gemma 產生之輸出的權利
- 使用者仍需自行負責輸出內容及後續用途
- 條款可能更新，正式部署前應重新查閱當時有效版本

## 個人使用與地端伺服器

Hosted Service 被列入 Distribution 不代表禁止架設地端伺服器，而是表示服務一旦提供給第三方使用，就需要依 Distribution 條款處理，不能只當作個人本機使用

| 使用情境 | 判斷 | 建議處理方式 |
| --- | --- | --- |
| 個人電腦僅供本人使用 | 通常不涉及向第三方提供功能 | 自行閱讀並遵守 Gemma Terms |
| 個人伺服器僅供本人連線 | 通常仍屬個人使用 | 限制存取並避免開放給他人 |
| 校內伺服器提供學生使用 | 可能屬 Hosted Service 與 Distribution | 依條款建立使用規則並由學校確認 |
| 公司內部伺服器提供員工使用 | 是否屬第三方需依法律關係判斷 | 由組織法務或管理單位確認 |
| 將模型權重放入隨身碟、NAS 或安裝套件 | 屬模型重新散布的可能性高 | 依 Distribution 條款準備必要文件 |
| GitHub 只發布說明文件、Compose 與腳本 | 未提供模型權重 | 保留模型來源及授權連結 |

## 模型輸出聲明

目前 Gemma Terms 沒有要求每一則模型回答都必須附加固定聲明

## 降低散布風險的發布方式

- GitHub 只提供說明文件、Compose 與腳本，不包含 Gemma 模型權重
- 每位使用者自行下載 `gemma3:4b`
- 模型只在使用者自己的電腦執行
- 改為共用伺服器時，需依 Hosted Service 情境補充使用條款與管理措施

## 未成年人

Gemma Terms 要求使用者具有同意條款的法律能力；若使用者未達可自行同意的年齡，應由負責單位依所在地規定確認同意方式
