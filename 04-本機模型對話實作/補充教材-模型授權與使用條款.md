# 補充教材-模型授權與使用條款

本文件供需要比較模型授權與使用情境的學生及教師查閱，不取代正式授權條款或法律意見

條款可能更新，正式部署、修改、重新散布模型或提供他人使用前，應以當時有效的官方文件及組織規範為準

## 免費、公開權重與開源授權

| 概念 | 意義 |
| --- | --- |
| 免費 | 目前不需要支付模型下載或本機推論費用 |
| 公開權重 | 使用者可以取得模型權重並在自己的電腦執行 |
| 開源授權 | 需要檢查是否允許使用、修改與散布，以及必須遵守哪些條件 |

免費、公開權重與開源授權代表不同概念，不能因模型可以免費下載，就推定可以不受條件地修改或重新散布

## 本課程模型與 MIT 授權

本課程使用：

```text
phi4-mini:3.8b-q4_K_M
```

Phi-4 Mini 由 Microsoft 開發，官方模型資料標示為 MIT License

MIT License 允許使用、複製、修改、合併、發布、散布、再授權及銷售軟體副本，但重新散布時必須在軟體副本或重要部分保留版權與授權聲明；授權也明確表示模型按現況提供，不附帶保證

若要重新散布模型檔案，除了閱讀 MIT License，也應查看官方模型儲存庫中的 LICENSE、NOTICE 與模型說明，確認實際發布內容及需要保留的文件

## 其他授權比較

| 授權 | 使用與修改 | 重新散布時的主要要求 | 備註 |
| --- | --- | --- | --- |
| MIT | 允許 | 保留版權與授權聲明 | 本課程 Phi-4 Mini 使用 |
| Apache 2.0 | 允許 | 附授權文件、保留適用的 NOTICE 並標示修改 | IBM Granite 系列使用 |
| Gemma Terms | 允許但受 Google 條款約束 | 傳遞條款、使用限制與指定 Notice | 另受 Gemma 禁止用途政策限制 |

MIT 與 Apache 2.0 是 OSI 認可的開源授權

OSI 是 Open Source Initiative（開放原始碼促進會）的縮寫，負責維護開源定義並審核授權是否符合自由使用、修改與分享的條件；OSI 認可不代表模型品質、安全性或所有使用情境都已獲得法律保證

Gemma 使用 Google 專屬條款，更適合稱為免費公開權重模型；它保留在本文件中作為比較案例，不是本次課程指定模型

## 個人使用與地端伺服器

| 使用情境 | 本課程模型的判斷 | 建議處理方式 |
| --- | --- | --- |
| 個人電腦僅供本人使用 | 可依 MIT License 在本機使用 | 保留模型來源與授權連結 |
| 個人伺服器僅供本人連線 | 授權條件不因改用個人伺服器而消失 | 限制存取並保護帳號與文件 |
| 校內或公司伺服器提供多人使用 | MIT License 沒有另設 Hosted Service 條款 | 仍應確認組織政策、個資、資安與資料授權 |
| 將模型權重放入隨身碟、NAS 或安裝套件 | 可能涉及重新散布模型 | 保留 LICENSE、NOTICE 及官方要求的文件 |
| GitHub 只發布說明文件、Compose 與腳本 | 未提供模型權重 | 保留模型來源及授權連結 |

開源授權處理的是模型檔案的使用與散布條件，不會取代個人資料、機密文件、著作權、資安及組織管理規範

## Gemma Terms 比較案例

若另行測試 `gemma3:4b`，需注意它使用 Google Gemma Terms，而不是 MIT License

- 使用者可以使用、重製、修改及散布 Gemma，但必須遵守 Gemma Terms
- Gemma 禁止用途政策屬於條款的一部分
- Distribution 包含提供模型或衍生模型，也包含透過 Web、API 或其他遠端方式提供功能的 Hosted Service
- Google 不主張使用者透過 Gemma 產生之輸出的權利
- 使用者仍需自行負責輸出內容及後續用途
- 條款可能更新，正式部署前應重新查閱當時有效版本

以上內容只用於比較不同模型授權，不代表本課程需要下載 Gemma

## 模型輸出與使用責任

模型採用 MIT、Apache 2.0 或其他授權，不代表每一則輸出都正確、安全或可以不經查核直接使用

使用者仍需確認：

- 輸出是否包含錯誤或沒有依據的內容
- 輸入資料是否涉及個人資料、機密或未授權文件
- 輸出用途是否符合著作權、組織規範及所在地法律
- 對外提供服務時是否需要額外的使用規則、風險告知與管理措施

## 本課程降低散布風險的方式

- GitHub 只提供說明文件、Compose 與腳本，不包含模型權重
- 每位使用者透過 Ollama 自行下載 `phi4-mini:3.8b-q4_K_M`
- 模型只在使用者自己的電腦執行
- 若改為共用服務或重新散布模型，應重新檢查官方 LICENSE、NOTICE、模型資料與組織規範
